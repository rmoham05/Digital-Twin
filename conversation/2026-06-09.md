# Conversation Log - 2026-06-09

## Question

The user reviewed the TwinOps Command Center desktop app and asked whether the displayed numbers are real or fake, and how the app will be used in practice.

## Clarification

The current build is a professional prototype / MVP shell. The interface is real, the desktop installer is real, and the web deployment path is real, but the telemetry numbers are currently simulated mock data.

## Practical Path

To turn it into a live digital twin, the app needs:

- Real asset list for the target building/factory/site.
- Sensor data source such as MQTT, REST API, CSV import, BACnet, Modbus, OPC UA, or a BMS/SCADA export.
- Backend ingestion service.
- Time-series database for readings.
- Rules/anomaly engine for health scores, alerts, and maintenance recommendations.
- User workflows for operators, maintenance, and management.
